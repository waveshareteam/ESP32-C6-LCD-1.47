# LVGL_Arduino

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Demonstrates the LVGL user interface on the board display.

## Hardware Required

- ESP32-C6-LCD-1.47 development board

## How to Run

1. Install Arduino-ESP32 `3.0.7`.
2. Open `LVGL_Arduino.ino` and select `ESP32C6 Dev Module`.
3. Upload the sketch.

## Expected Result

The display initializes and renders the LVGL demonstration interface.
