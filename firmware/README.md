# Factory Firmware

[English](README.md) | [简体中文](README_ZH.md)

The tested factory BIN for ESP32-C6-LCD-1.47 belongs in this directory. It must be named `ESP32-C6-LCD-1.47_FactoryOnly_<YYYYMMDD>.bin`, be a single merged image flashed from `0x0`, and include its SHA-256 in this file before release.

The source workspace did not retain a recoverable copy of the previously listed 2026-02-03 BIN. Add the verified binary and update this document before publishing.
